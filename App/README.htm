ScriptureGuide 1.0.0

Welcome to ScriptureGuide, the Bible study program for Haiku.

Current features include:

  • Any number of Bibles, commentaries, or personal-notes columns shown side by side, kept aligned on the same verse
  • Drag and drop of selected verses between columns, to the Desktop, or to other applications, and back again
  • A single Go to / Search field that jumps straight to a typed reference or runs a search, whichever the text turns out to be
  • Search within whichever translation is currently open, with a picker for which one if more than one column is open
  • Personal notes per verse
  • Translated interface (German among other languages) with locale-aware verse references
  • A Book Manager (Program menu -- Book Manager...) to download and remove Bibles and commentaries, with a consent warning before any network access
  • Set the reading font, hide verse numbers, and other display options

Planned features:

  • Search across more than one open translation at once (currently one translation per search, selectable from whichever columns are open)
  • Support for Strong's numbers
  • Support for module types beyond Bibles and commentaries

Known limitations:

  • Hebrew is displayed left to right, a limitation of the underlying text view
