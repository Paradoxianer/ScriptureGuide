ScriptureGuide 1.5.0

Welcome to ScriptureGuide, the Bible study program for Haiku.

Current features include:

  • Any number of Bibles, commentaries, or personal-notes columns shown side by side. Columns can be linked into "chains" that scroll and navigate together, or split off to browse independently at their own pace -- each chain keeps its own book/chapter/verse and its own scrollbar
  • Drag and drop of selected verses between columns, to the Desktop, or to other applications, and back again
  • A single Go to / Search field that jumps straight to a typed reference or runs a search, whichever the text turns out to be
  • Search within whichever translation is currently open, with a picker for which one if more than one column is open -- your own notes included
  • Cross-reference detection in commentary text, clickable to jump straight there
  • Marking passages in six colours, inside one translation or verse-wide across all columns
  • Strong's numbers: hover a word for its number and a short gloss, click it to look it up and light up every occurrence in the chapter
  • Word study: search by Strong's number, browse a whole lexicon in the dictionary window, and see where hits fall in a per-chapter Hits Chart
  • Verse lists: named, nestable collections of references with tags, stored as ordinary files Tracker can browse
  • Personal notes per verse, saved automatically
  • Structured export ("Copy Comparison") as plain text, tab-separated, Markdown, or HTML, and printing of the reading pane and of verse lists
  • Column layout -- which modules are open, notes, and how columns are linked -- is restored automatically the next time you start the app
  • Translated interface (German among other languages) with locale-aware verse references
  • A Book Manager (Program menu -- Book Manager...) to download and remove Bibles, commentaries, and dictionaries, with a consent warning before any network access
  • Set the reading font, hide verse numbers, and other display options

Planned features:

  • Search across more than one open translation at once (currently one translation per search, selectable from whichever columns are open)
  • Support for module types beyond Bibles, commentaries, and dictionaries

Known limitations:

  • Hebrew is displayed left to right, a limitation of the underlying text view
