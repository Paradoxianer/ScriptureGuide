Scripture Guide Installation

This is for installation from source. The source is released under the GNU Public License.

If you just want to use Scripture Guide, the easiest way is via HaikuDepot or pkgman install scriptureguide, once the package is available in your repository. This page is for building it yourself.

I. Compiling and installing Scripture Guide

This software is only for Haiku. It will not compile on any other platform. It also requires the SWORD library, which can be installed with pkgman install sword sword_devel, or built from the recipe in haikuports using haikuporter.
  1. Run make in the ScriptureGuide and ScriptureGuideManager directories and copy the App directory to wherever you want.
  2. Use ScriptureGuideManager (or the "Book Manager..." entry in Scripture Guide's own Program menu) to download books.

II. Other Notes

You will need to have a special font if you would like to use modules written in Greek. Here are links to some Greek fonts which are free for the download:

  • Aristarcoj
  • BSTFonts
  • bwfonts - fonts from BibleWorks
